# Installation

## Requirements

- Rust 1.94.0 or later
- Network access to a Nostr relay

## Build from source

```bash
git clone https://github.com/MostroP2P/mostro-score.git
cd mostro-score
cargo build --release
```

The binary is at `target/release/mostro-score`.

## Install globally

```bash
cargo install --path .
```
